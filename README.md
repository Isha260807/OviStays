# OviStays

Hotel management platform with three modules: **admin**, **user**, **hotel**.

- `Backend/`  Node + Express + MongoDB API (`src/modules/{admin,user,hotel}`, shared code in `src/core`)
- `Frontend/` React + Vite + Tailwind web app (`src/modules/{admin,user,hotel}`, shared code in `src/shared`)
- `Apps/`     React Native apps (planned, not started)
